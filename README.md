# 员工管理系统 使用说明

## 项目简介

本项目是一个基于纯 HTML / CSS / JavaScript 实现的**员工管理系统**，无需任何后端服务器，直接在浏览器中打开即可使用。

---

## 文件结构

```
员工管理项目/
├── login.html   # 登录页面
├── index.html   # 主界面（需登录后访问）
├── style.css    # 全局样式
├── auth.js      # 登录逻辑与鉴权
├── main.js      # 主界面交互逻辑
└── README.md    # 使用说明（本文件）
```

---

## 快速开始

1. 直接用浏览器（推荐 Chrome / Edge）打开 `login.html` 文件。
2. 输入初始管理员账号登录：

   | 账号 | 密码   |
   |------|--------|
   | root | 123456 |

3. 点击「登录」按钮，验证通过后自动跳转到主界面。

> **注意**：若直接访问 `index.html`，系统会检测到未登录状态，并自动跳转回登录页。

---

## 界面说明

### 登录页（login.html）
- 浅蓝色渐变背景，卡片式登录框。
- 仅提供登录功能，输入账号和密码后点击「登录」。
- 账号或密码错误时显示错误提示并触发抖动动画。

### 主界面（index.html）
- 浅蓝色渐变背景，顶部导航栏 + 左侧菜单 + 内容区三栏布局。
- **顶部导航栏**：显示系统名称、当前登录用户，提供「退出登录」按钮。
- **左侧菜单**（点击切换内容区）：
  - 📊 控制台：显示员工总数、部门数量等统计概览。
  - 👥 员工列表：展示员工信息表格，支持搜索与新增入口。
  - 🏢 部门管理：展示部门信息表格。
  - 📅 考勤管理：模块占位页，后续版本开放。
  - 💰 薪资管理：模块占位页，后续版本开放。
  - ⚙️ 系统设置：显示当前账号、角色及版本信息。

## 账号管理说明

- 初始账号存储在 `auth.js` 文件的 `USERS` 数组中，格式如下：

  ```js
  const USERS = [
    { username: 'root', password: '123456', role: '管理员' }
  ];
  ```

- 如需新增账号，直接在 `USERS` 数组中添加新对象即可，例如：

  ```js
  { username: 'admin2', password: 'abcdef', role: '普通管理员' }
  ```

- 登录状态通过浏览器 `sessionStorage` 保存，关闭标签页后会话自动清除，需重新登录。
