## 日常启动（两台 cmd 或一键脚本）

**方式 A — 推荐**

双击：`启动测试环境.bat`

**方式 B — 手动**

```powershell
# 终端1：后端
cd "D:\Documents\QQdownload\员工管理项目\员工管理项目\server"
node server.js

# 终端2：前端（Selenium 用）
cd "D:\Documents\QQdownload\员工管理项目\员工管理项目"
npx --yes http-server -p 8080 -c-1
```

浏览器访问：http://localhost:8080/login.html

## 运行自动化

双击：`运行自动化测试.bat`

或在 Eclipse 中导入 `ems-selenium-test` 后 Run JUnit Test。

## 数据库密码不一致时

修改 `server/server.js` 第 16 行 `password` 为你的 MySQL 密码，并重启 `node server.js`。

## 首次在新电脑部署

1. 安装 MySQL 8、Node 16+、JDK 17+、Chrome  
2. `mysql -u root -p < ems_database.sql`（若有导出文件）  
3. `cd server && npm install`  
4. 按上文启动后端与 http-server  
5. （可选）无需单独安装 Maven，使用本项目 `tools/apache-maven-3.9.6`
